Setting up Ketch

On this computer
Install the Ketch desktop app and open it once, so your browsers can find it. After that, the extension opens Ketch whenever a download needs it; there is no server to turn on or token to copy.
On another device
On that device, open Settings → Sharing and choose Allow another device. Add the device here with Add server, the address Ketch shows, such as http://192.168.1.20:8642, and the Access code under Advanced as its access token. For ketch server, set apiToken in its config.toml.
Command line or sandboxed browsers
To use ketch server on this computer, or from a browser installed as a Flatpak or Snap, which can't start other apps, add it as a server at http://127.0.0.1:8642.

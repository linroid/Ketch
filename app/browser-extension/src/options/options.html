Setting up Ketch

On this computer
Open the Ketch app, go to Settings → Remote access and turn on Server. Turn on Start automatically so the extension works whenever Ketch is open. With the command line, run ketch server.
On another device
On that device, turn on Server and Allow other devices, then generate an access token. Add the device here with its address, such as http://192.168.1.20:8642, and the token. For ketch server, set apiToken in its config.toml.
